## 6. FREQUENZBERECHNUNG

### 6.1 Formel für Glockenfrequenz

```
f = (k × t) / (D² × √ρ)

Wobei:
f = Frequenz (Hz)
k = Materialkonstante (Bronze ≈ 0.557)
t = Wandstärke am Schlagring (mm)
D = Durchmesser (mm)
ρ = Dichte (kg/m³)
```

### 6.2 Berechnung für 432 Hz

```
Ziel: f = 432 Hz

Mit Bronze (ρ = 8800 kg/m³):
432 = (0.557 × 21) / (D² × √8800)
432 = 11.697 / (D² × 93.8)

D² = 11.697 / (432 × 93.8 × 10⁻⁶)
D² = 0.000289 m² = 289 cm²
D = 17 cm = 170 mm

→ Skalierung auf D = 233 mm erfordert
   Wandstärke-Anpassung auf 21 mm ✓
```
